# เช็คสต๊อกสินค้า (เครื่องมือชั่วคราว)

หน้าเว็บสำหรับให้ทีม 2-3 คนช่วยกันเดินเช็คสต๊อกจริงในบริษัท คนละมือถือ ติ๊กสินค้าที่ยังมี/ยังขายอยู่
ข้อมูลที่ติ๊กจะไปรวมกันที่ Google Sheet เดียวกัน (ฟรี ไม่ต้องผูกบัตร)

**ไม่เชื่อมกับเว็บหลัก** ไม่มีลิงก์จากเมนู ใช้เสร็จแล้วลบโฟลเดอร์นี้ทิ้งได้เลย

---

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ก่อนเริ่มเดินเช็คสต๊อก)

### ขั้นที่ 1 — สร้าง Google Sheet
1. เปิด https://sheets.google.com → สร้างชีทใหม่ ตั้งชื่อ เช่น "Sangudom Stock Check"
2. ไม่ต้องพิมพ์อะไรในชีท (ระบบจะสร้าง header ให้อัตโนมัติตอนใช้งานจริง)

### ขั้นที่ 2 — ใส่โค้ด Apps Script
1. ในชีทที่สร้าง ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ด default ทั้งหมดในไฟล์ `Code.gs`
3. เปิดไฟล์ `stock-check/apps-script/Code.gs` ในโปรเจคนี้ **copy โค้ดทั้งหมด** ไปวางแทน
4. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)

### ขั้นที่ 3 — Deploy เป็น Web App
1. มุมขวาบน กด **Deploy (ปรับใช้) → New deployment (การทริปใหม่)**
2. ไอคอนเฟือง ⚙️ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - **Execute as (เรียกใช้ในฐานะ):** Me (บัญชีของคุณ)
   - **Who has access (ผู้มีสิทธิ์เข้าถึง):** Anyone (ทุกคน)
4. กด **Deploy** → ระบบจะขอ authorize (อนุญาตสิทธิ์) → กด Advanced/Go to (ชื่อโปรเจค) (unsafe) → Allow
5. จะได้ URL หน้าตาแบบนี้: `https://script.google.com/macros/s/xxxxxxxxx/exec`
   **copy URL นี้เก็บไว้**

### ขั้นที่ 4 — ใส่ URL ในเว็บ
1. เปิดไฟล์ `stock-check/config.js`
2. ใส่ URL ที่ copy มาใน `WEB_APP_URL: "https://script.google.com/macros/s/xxxxxxxxx/exec"`
3. บันทึกไฟล์ แล้ว commit + push เข้า main (ให้ Claude ช่วย หรือทำตามขั้นตอน git ปกติ)

## วิธีใช้งานตอนเดินเช็คสต๊อก

1. ส่งลิงก์ให้ทีม: `https://anirut-dev.github.io/websangudom/stock-check/`
2. แต่ละคนเปิดลิงก์ในมือถือ **ใส่ชื่อตัวเอง** ในช่องบนสุด (ช่วยให้รู้ว่าใครเช็คอันไหน)
3. ใช้ **filter หมวด** หรือ **ค้นหา** เพื่อโฟกัสทีละโซน
4. เจอสินค้าตัวไหนของจริง → ติ๊กถูก (บันทึกอัตโนมัติ ไม่ต้องกดบันทึก)
5. กด **🔄 รีเฟรช** เป็นระยะ เพื่อดูว่าคนอื่นติ๊กอะไรไปแล้วบ้าง (กันติ๊กซ้ำ)
6. เช็คเสร็จ → เปิด Google Sheet ดูสรุปได้เลย หรือกด **⬇️ ดาวน์โหลด CSV** จากหน้าเว็บ

## อ่านผลสรุป

ใน Google Sheet คอลัมน์ "ติ๊กแล้ว":
- `TRUE` = มีของจริง ยังขายอยู่ → เก็บไว้ในเว็บ
- แถวที่ไม่มีเลย (ไม่เคยถูกติ๊ก) = ไม่มีของจริง/หาไม่เจอ → เป็นตัวเก็งที่ต้องพิจารณาคัดออกจากเว็บ

## เลิกใช้แล้วจะลบยังไง

ลบโฟลเดอร์ `stock-check/` ทั้งโฟลเดอร์ออกจาก repo, commit, push — เว็บหลักไม่กระทบอะไรเลย
(จะลบ Google Sheet + Apps Script ทิ้งด้วยก็ได้ ไม่เกี่ยวกับเว็บ)
